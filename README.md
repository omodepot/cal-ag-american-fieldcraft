# CAL-AG — American Fieldcraft

A high-fidelity homepage concept for CAL-AG Enterprises, Inc.

This direction is cinematic, editorial, and heritage-led, pairing agricultural machinery photography with CAL-AG’s real company history, equipment focus, service positioning, and Fowler, California contact information.
