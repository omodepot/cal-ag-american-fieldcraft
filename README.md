# CAL-AG — American Fieldcraft

A high-fidelity homepage concept for CAL-AG Enterprises, Inc.

This direction is cinematic, editorial, and heritage-led, pairing agricultural machinery photography with CAL-AG’s real company history, equipment focus, service positioning, and Fowler, California contact information.

## Review

Open `index.html` in a browser. This is a design concept only and does not modify the live CAL-AG website.

Photography supplied by the client.

## WordPress theme deployment

The custom theme lives in `wordpress-theme/cal-ag-fieldcraft/`.

- `staging` deploys automatically to the DreamHost **staging** site once GitHub secrets are set.
- `main` holds approved production releases only. Production installs are manual, from tagged GitHub Releases.

See [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md), [docs/RELEASING.md](docs/RELEASING.md),
[docs/ROLLBACK.md](docs/ROLLBACK.md) and [docs/BACKUPS.md](docs/BACKUPS.md).
Database and media backups are handled outside Git.
